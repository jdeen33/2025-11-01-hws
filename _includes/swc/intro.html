Software Carpentry HWS-Astronomy is hosting an introductory programming and digital skills bootcamp for beginner and intermediate programmers. This intensive, 2-day workshop will provide students with a basic foundation of Python programming for data analysis along with an introduction to the fundamentals of the Unix shell for efficient command-line operations, Git for program version control and collaboration, and SQL for managing and querying databases

For more information on what we teach and why, please see our paper "Best Practices for Scientific Computing".
